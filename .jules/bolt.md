## 2025-05-19 - Fast Chunk Frame Loop `std::vector` Optimization
**Learning:** In the performance-sensitive frame loop (`ChunkManager::uploadToGPU`), short-lived collections of bounded size (like `published` and `processedGroups` which are capped per frame) incur unnecessary dynamic allocation and node-chasing overhead when using `std::unordered_set`. Since these sets are completely cleared every frame, hash maps are an anti-pattern compared to contiguous arrays.
**Action:** When tracking unique elements in bounded, short-lived hot loops where items are cleared rapidly, use `thread_local std::vector` paired with linear search (`std::find`). This takes advantage of O(1) CPU cache locality, eliminates heap allocation, and significantly outperforms hash node insertions despite the O(N) lookup.
